# ContactFlow

Official project page and release repository for:

> **ContactFlow: A Video Action Conditioning that Transfers Across Embodiments**

ContactFlow is an embodiment-agnostic action representation for video world
models. It encodes manipulation through trajectories of 3D contact points
between an actor and a target object.

## Status

This repository and the associated project page are under construction. The
paper, implementation, checkpoints, and data-processing tools will be added as
they become available.
